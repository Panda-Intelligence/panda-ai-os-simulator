# Panda AI OS Simulator

This is the standalone open-source simulator repository. Panda-owned code is
licensed under MIT. Keep upstream copyright notices and do not treat this
license as permission to redistribute unresolved guest, ROM, font, media, or
other third-party materials.
Preserve native/QEMU and browser behavior; framebuffer events must originate in
real guest execution. No fake boot images.
No user books, fonts, ROM, caches, secrets or Murphy history are exported.
Changes belong to scoped lanes; main alone commits/pushes and owns manifests.
Only scoped tests; no full QEMU/device build without integrator coordination.
All new docs in English. New external paths must be explicit, never guessed.
