# Launch owner checklist — NOT approved for publication

D0 is defined only after G0-G3 pass. No fixed launch date is set.

| Gate | Evidence required | Current |
|---|---|---|
| G0 | File ownership, code license, guest/ROM/media permission | Pending #1 |
| G1 | Three external clean builds and real minimal guest starts | Pending #2 |
| G2 | Fixed Murphy reference, native/browser/product journeys | Pending #2 |
| G3 | Supported-browser matrix, origins/data recovery, rollback | Pending |
| G4 | Claims matched to actual deployed version and licensed media | Pending |

Before any posting: record release/guest/runtime SHA, verify a no-login real
sample journey, produce one normal-speed 45–60 second video and a 15–20 second
preview using authorized content, and document browser and hardware limitations.
At least three gallery images should show reading, developer tools and capability
limits. No existing user book image or device log is a marketing asset.

X D0: real demo and project link. Reddit D+1 onward: one approved community at
a time with affiliation disclosure and substantial technical detail. Product
Hunt D+3–7 after early fixes: actual maker identity, clean product URL, gallery,
limits and request for feedback (not votes). HN: actual developer writes their
own original submission/comments; current guidelines prohibit generated or
AI-edited text. Do not copy the factual brief as a post.

Measure launch_requested → real guest_interactive → sample_opened →
demo_completed. Do not collect book names, text, import paths or raw logs.
Separate unsupported environments from successful sessions in the denominator.
